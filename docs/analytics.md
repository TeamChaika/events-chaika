# Посещаемость афиши

Яндекс Метрика, счётчик **113085427**, принадлежит аккаунту владельца сайта. Для просмотра отчётов войдите в [Метрику](https://metrika.yandex.ru/list), выберите счётчик сайта и отчёт «Посещаемость»: посетители, визиты, просмотры по выбранному периоду. Данные до установки не восстанавливаются. Блокировщики, отказ от аналитики и отключённый JavaScript исключают посещение из клиентской статистики.

## Границы сбора

- `src/analytics.ts` — ID, загрузка после согласия, очищенные адреса, запрет запуска вне главной страницы production-домена.
- `src/Legal.tsx` — две равноправные кнопки выбора и повторное открытие настроек.
- `server/index.mjs` — CSP разрешает `mc.yandex.ru` только для `/`. Никаких `unsafe-inline` для JavaScript, `unsafe-eval` или доступа к iframe сотрудников.
- Вебвизор, карта кликов, отслеживание ссылок, ecommerce и Тег Менеджер выключены. Автоматический просмотр отключён через `defer`, отправляется один явный `hit` с адресом `https://event.chaika.team/` и без содержимого формы.
- На `/ticket/*`, `/order/*`, `/admin`, `/checkin`, `/unsubscribe/*`, юридических страницах, localhost и техническом домене счётчик не загружается. Эти посещения в отчёт не входят.
- Cookie-выбор привязан к версии `2026-09-26.2` и учитывается 180 дней. Прежняя кнопка «Понятно» не даёт разрешения аналитики. После отзыва код останавливается и страница обновляется. Ранее отправленные данные автоматически не удаляются.

## Проверка

`node --test tests/analytics.test.mjs` проверяет отсутствие загрузки без разрешения, исключение персональных маршрутов, очистку URL, однократный просмотр, отзыв при медленной загрузке и блокировку скрипта. Тест production CSP находится в `tests/api.test.mjs`. `npm run build` проверяет TypeScript и сборку.

В браузере: до выбора и после отказа нет элемента `script[src*="mc.yandex.ru"]`; после разрешения на боевой главной загружается tag.js, а его `data-analytics` меняется с `loading` на `initialized`, затем на `sent` по callback метода hit. Callback подтверждает обработку вызова библиотекой; появление визита в отчёте нужно проверять в кабинете владельца, оно не доказывается одной загрузкой скрипта. После отзыва и обновления страницы скрипта снова нет. Покупка доступна при любом выборе.
