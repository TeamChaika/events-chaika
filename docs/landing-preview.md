# Вариант расширенного лендинга для согласования

Публичный адрес для согласования: `https://event.chaika.team/test-lending`.
Локальный адрес: `http://localhost:5174/test-lending`.

Исходный афишный блок, интро с луной, форма покупки и мобильная кнопка сохранены. Ниже бегущей строки добавлены описание события, расписание двух сцен с шестью афишами, дресс-код с галереей из восьми образов, предварительный блок организаторов и заключительная кнопка покупки.

Содержание: `Разделы на Лендинг.docx`, переданный 1 октября 2026. Время сбора — 20:30; расписание и имена взяты из этого документа. Факты афиши берутся из обычного API мероприятия. Текст об организаторах требует согласования; история прошлых мероприятий не выдумывалась.

2 октября 2026 пользователь передал готовые афиши всех шести артистов. Они сохранены в WebP без обрезки и показаны целиком в формате 4:5; на телефонах — по одной в ряд. Написание имён в подписях приведено к афишам, время выступлений не изменено. Из дресс-кода убраны «Быть собой» и крупная декоративная кавычка над цитатой.

Для артиста без готовой афиши предусмотрена размытая заглушка «Афиша скоро». Ранее сгенерированные портреты вымышленных людей сохранены только как фон этих заглушек; без размытия они не показываются. Файлы и полные промпты находятся в `landing-preview-assets.json`. Восемь фотографий дресс-кода скачаны из указанной в документе папки Яндекс Диска; сохранены в WebP для сайта.

## Изоляция и запуск

Компонент `src/LandingPreviewSections.tsx` загружается лениво только по пути `/test-lending` (также поддерживается завершающий слеш). CSS ограничен классами `lp-*`. Главная `/` не загружает и не показывает новые разделы. Тестовый маршрут отдаёт `X-Robots-Tag: noindex, nofollow`, чтобы черновик не индексировался. Публичная страница использует обычные сведения о мероприятии и форму покупки; пометки о предварительных материалах сохранены.

Для текущего просмотра запущены Vite на 5174 и изолированный API на 8787. API использует временную SQLite в памяти, тестовый режим, без файла секретов и без фоновой отправки уведомлений. Снимок общедоступной афиши сохранён в `.deployment/landing-preview/events.json`.

Перезапуск из корня проекта в двух терминалах:

```sh
node .deployment/landing-preview/server.mjs
npx vite --host 127.0.0.1 --port 5174 --strictPort
```

Публикация отдельного маршрута согласована пользователем. Перенос разделов на `/` — отдельный последующий шаг после согласования менеджерами.
